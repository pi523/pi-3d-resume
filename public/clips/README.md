# AI 蓝幕片段：生成方法与落位

把生成好的 mp4 按下面文件名放进本目录即可生效（文件不存在时页面不显示任何东西）：

- `desk.mp4` — 坐着敲电脑（8 秒循环），显示在主页 Works 两扇门那一屏右下角
- `fall.mp4` — 坠落（6 秒），显示在页脚前的结尾一屏

要求：16:9、纯蓝幕背景 #0000FF、静音。抠像参数在 `src/ui/KeyedVideo.tsx`（similarity / smoothness / spill）。

## 用哪个网站

（国内版即梦已无免费额度，用下面这些）
- 首选 **Dreamina** dreamina.capcut.com（即梦海外版，同一套 Seedance 模型，免费每天 120 积分）：AI Video → 图生视频 / 参考图，5–8 秒，16:9
- **可灵 Kling** app.klingai.com（每天 66 免费积分）
- **PixVerse** app.pixverse.ai（注册 90 + 每天 60，支持多图参考）
- **Vidu** vidu.com（有免费积分，多参考图融合）

## 片段 1 · desk.mp4

以@图片1 作为唯一人物参考，生成一条 8 秒、16:9、固定镜头、静音、可无缝循环的 3D 黏土卡通视频。人物：Q 版大头女孩，深棕色长直发中分，粉色衬衫外套，白色吊带，脸颊贴着彩色小贴纸，怀里一只蓝眼白色布偶猫。场景：人物坐在画面右下角的小沙发上，膝上放着打开的笔记本电脑，白猫趴在旁边；人物低头敲键盘，偶尔抬头看一眼屏幕再笑一下。背景为纯色蓝幕 #0000FF，无任何纹理和阴影。严格保持人物脸型、发型、服装、贴纸位置和猫的外观；禁止镜头运动、背景变化、贴纸漂移、额外人物、字幕和水印。第一帧与最后一帧姿态一致。

## 片段 2 · fall.mp4

以@图片1 作为唯一人物参考，生成一条 6 秒、16:9、固定镜头、静音的 3D 黏土卡通视频。人物描述同上：Q 版大头女孩，深棕色长直发中分，粉色衬衫外套，白色吊带，脸颊贴着彩色小贴纸，怀里一只蓝眼白色布偶猫。动作：人物从画面上方缓慢飘落，四肢张开、表情惊讶但开心，怀里仍抱着白猫；周围同步飘落一台笔记本电脑、一个紫色游戏手柄、几个圆角方形图标（抽象图形，不要真实 logo）。背景为纯色蓝幕 #0000FF。严格保持人物身份、服装、贴纸和猫；禁止镜头运动、背景变化、变形、额外人物、字幕和水印。

## 要点

- 背景必须是均匀纯蓝 #0000FF；有渐变/阴影就加一句"背景为完全均匀的纯蓝色，无光照变化"重生成
- 丢猫/丢贴纸：把失败视频当 @视频1 再传，提示词开头加"参考@视频1 的动作，但人物必须严格按@图片1：怀里有白猫、脸上有贴纸"
- 先做片段 1 确认一致性，再做片段 2
